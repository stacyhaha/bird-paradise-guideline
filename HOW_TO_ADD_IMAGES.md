# 🖼️ How to Add Your Own Bird Images

## 📁 Images Folder Structure

I've created a folder called `images/` with placeholder files for all 64 birds. Each bird has a corresponding image file named `{bird-id}.jpg`.

## 🔄 How to Replace Images

### Method 1: Direct File Replacement

1. **Find the bird you want**: Look in the `images/` folder for the bird's file
2. **Download your image**: Get the image from the official website or other sources
3. **Replace the file**:
   - Rename your downloaded image to match the exact filename
   - Replace the placeholder file in the `images/` folder
4. **Refresh the website**: The new image will appear automatically!

### Method 2: Screenshot from Official Website

1. **Visit**: https://www.mandai.com/en/bird-paradise/animals-and-zones.html
2. **Find the bird**: Navigate to the specific zone and bird
3. **Take screenshot**: Capture the bird's image
4. **Save and rename**: Save as `{bird-id}.jpg` in the `images/` folder
5. **Replace**: Overwrite the placeholder file

## 💡 Tips

- **Image format**: Use JPG, PNG, or WebP format
- **Image size**: Recommended 400x300 pixels or similar aspect ratio
- **File size**: Keep under 2MB for best performance
- **Naming**: Must match the exact filename (case-sensitive)
- **Location**: All images go in the `images/` folder

## ✅ Testing

After replacing images:

1. Open `index.html` in your browser
2. Navigate to the bird you updated
3. The new image should appear automatically
4. No need to restart or refresh anything else!
